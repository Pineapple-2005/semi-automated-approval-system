Flag Reference — Where Errors Are Detected

All flags result in needs_review. The admin panel displays these structured strings so reviewers know exactly what was wrong.

Flag (prefix) Detection Layer Example value Admin action
blurry_image Image quality (OpenCV Laplacian) blurry_image:laplacian=42.3:threshold=100 Ask user to resubmit clearer photo
poor_lighting Image quality (brightness) poor_lighting:brightness=28.1:reason=too_dark Ask user to photograph in better light
missing_required_field OCR extraction completeness missing_required_field:prc_number:doc_type=medical_license Check if field is obscured; resubmit or manually enter
low_ocr_confidence Tesseract word confidence low_ocr_confidence:avg=48%:threshold=60% Image quality issue; resubmit higher-res scan
name_mismatch Fuzzy name comparison name_mismatch:similarity=62%:extracted=DELA CRUZ J:expected=JUAN DELA CRUZ Verify identity manually; check for aliases
org_name_mismatch Fuzzy org-name comparison org_name_mismatch:similarity=55%:extracted=PAG-ASA FOUNDATION:expected=PINAS FOUNDATION Confirm organisation identity; check for name changes
dob_mismatch Date-of-birth comparison dob_mismatch:extracted=01/15/1990:expected=01/15/1989 Verify DOB; possible OCR digit swap
expiry_check Expiry date vs today expiry_check:expired=2023-06-30 Inform user; request updated document
document_type_mismatch ORB template classifier vs submitted type document_type_mismatch:expected=medical_license:detected=drivers_license Confirm correct document was uploaded
medical_profession_not_licensed Profession whitelist check medical_profession_not_licensed:detected_profession=CIVIL ENGINEER BayaniHub only: verify medical volunteer credentials
invalid_sec_number_format SEC number regex validation invalid_sec_number_format:extracted=12345:expected=PREFIX+9-12digits Request clearer scan or correct SEC document
invalid_dti_registration_format DTI BN number regex validation invalid_dti_registration_format:extracted=BN-123:expected=BN-XXXXXXXXX-XX Request clearer scan or correct DTI certificate
partial_document Region coverage analysis (OpenCV) partial_document:coverage=41%:threshold=60% Ask user to resubmit showing full document
unrecognized_format ORB classifier low confidence unrecognized_format:classifier_confidence=low Manual review; may be unsupported or altered document

Status Flow

POST /api/v1/verify └─► status = "processing" │ ▼ Celery worker runs OCR + template matching + flagging │ ├─► flags == [] ──► status = "auto_approved" ──► webhook fired immediately │ └─► flags != [] ──► status = "needs_review" │ ▼ Admin fetches GET /api/v1/review/queue │ Reviews flags + presigned image URL │ ├─► POST /api/v1/review/{job_id} action="approve" │ └─► status = "approved" ──► webhook fired │ └─► POST /api/v1/review/{job_id} action="reject" └─► status = "rejected" ──► webhook fired NOTE: The API NEVER auto-rejects. Only a human reviewer can reject a document.
